# AGENTS.md

## Scope

This file provides repo-local orientation for agents working in `pyrojewel_claude_code`.

## Read First

- `CLAUDE.md`
- `README.md`
- `SETUP.md`
- `references/current-status-and-next-steps.md`
- `references/skill-source-map.md`
- `references/flow-map.md`

## Work Classification

Most work in this repo falls into one of these groups:

1. Paper flow
2. Idea / experiment flow
3. Hook / ECC runtime work
4. Public repo hygiene / docs / setup

## Canonical Editable Project Docs

Project-owned docs to maintain by hand:

- `CLAUDE.md`
- `AGENTS.md`
- `README.md`
- `SETUP.md`
- files under `references/`

## Do Not Treat As Canonical Project Guidance

Do not hand-maintain these as project memory:

- `.ccb/**`
- runtime-generated session files
- local learnings
- output artifacts
- temporary notes, screenshots, or personal cache files

## Skill Placement Rule

- Adopted skills belong in `skills/`
- Source provenance and sync policy belong in `references/skill-source-map.md`
- Do not treat external source repos as automatically mirrored into this repo

## Hook Boundary

- `session-start.js` / `session-end.js`
  - local context lifecycle
- `session-knowledge-summary.js`
  - optional external archive hook
- `evaluate-session.js`
  - local learning extraction

## Generated Output Governance

Specs and plans generated by Superpowers skills live in `docs/superpowers/`. They are **not** canonical project memory — they are coordination artifacts.

- Index: `docs/superpowers/README.md`
- Policy: `references/workflow-output-policy.md`
- Verify: `bash tools/verify-superpowers-index.sh`

## Public Repo Hygiene

Avoid committing:

- session state
- local learnings
- generated outputs
- personal notes
- screenshots
- machine-specific absolute paths

If local paths are required, use environment variables or clearly marked placeholders.
